# 使用说明：Spotlight 首版

本文面向开发者与测试，说明如何在本机跑起首版、如何操作一局、调试面板能用什么，以及常见问题如何排查。
玩法规则见 [玩法.md](玩法.md)，表格填写见 [策划填写说明.md](策划填写说明.md)，实现设计见 [最初版本实现方案.md](最初版本实现方案.md)。

## 1. 环境与依赖

| 项目 | 值 | 说明 |
|---|---|---|
| Unity | 2022.3.62f3c1 | 见 `ProjectSettings/ProjectVersion.txt`；不要替换为其他版本 |
| 渲染 | URP 2D（`com.unity.render-pipelines.universal` 14.0.12） | 工程已配置 URP 全局设置 |
| UI | UI Toolkit / UXML 1.0.0 + UGUI 1.0.0 + TextMeshPro 3.0.7 | 静态面板用 UXML，手牌与棋盘用 UGUI |
| 目标平台 | Windows | 首版只交付 Windows 桌面包 |

第三方依赖来源（均为随工程提交的本地副本，不通过包管理器安装）：

| 依赖 | 位置 | 作用范围 |
|---|---|---|
| ExcelDataReader 3.9.0 | `Assets/Plugins/ExcelDataReader/Editor/` | **仅编辑器**：读取 `.xlsx`；正式运行包不包含 Excel 解析器 |
| DOTween Free 1.2.765 | `Assets/Plugins/Demigiant/DOTween/`（含 `Editor/`、`Modules/`） | 运行时表现反馈（选中、部署、移动、受击） |
| SimHei 字体 | `Assets/Spotlight/Fonts/SimHei.ttf` | 仅用于本地中文显示验证；生成的 `SimHei SDF.asset`、`SimHei TextCore.asset` 由工具产出 |

> 汉字显示依赖生成的字体资产与 PanelSettings；若界面出现方框，见第 6 节。

## 2. 首次运行步骤（按顺序执行）

在 Unity 菜单中选择：

1. `Tools/Spotlight/生成默认工作簿`
   在 `Assets/Spotlight/Config/Spotlight.xlsx` 写出 6 张默认表（已存在时会先确认覆盖）。可用 `Tools/Spotlight/打开默认工作簿` 直接打开该文件。
2. 按 [策划填写说明.md](策划填写说明.md) 编辑工作簿（可选；默认值即可直接运行）。
3. `Tools/Spotlight/验证配置`
   只校验不写资产。全部通过时输出“校验通过”；有错时在 Console 一次性列出全部问题，格式为 `文件!表:行:列 原因`。
4. `Tools/Spotlight/编译全部配置`
   校验通过后生成只读配置资产与每卡种 Prefab；Console 会输出“编译完成，生成 N 个资产”。任何一项校验失败都不会改动已有产物。
5. `Tools/Spotlight/生成中文字体资产`
   生成 TMP/TextCore 字体资产与界面用的 PanelSettings；首次在干净工程运行前可先执行 `Tools/Spotlight/导入 TMP 基础资源`。
6. `Tools/Spotlight/生成演示场景`
   生成 `Assets/Spotlight/Scenes/Spotlight.unity` 并写入 Build Settings 第一位（会先确保字体资产与配置已编译）。可选：`Tools/Spotlight/重建外观模板` 用于重建卡牌外观模板。
7. 打开 `Assets/Spotlight/Scenes/Spotlight.unity`，点击 Play 运行。
   场景根节点上的 `GameBootstrap` 负责“加载配置 → 创建对局 → 绑定视图”；若配置缺失或非法，界面会显示“无法开局：…”而不是静默半初始化。

## 3. 程序集与目录结构

| 程序集 | 目录 | 引用 | 说明 |
|---|---|---|---|
| `Spotlight.Core` | `Assets/Spotlight/Core/` | 不引用引擎（`noEngineReferences`） | 配置契约与校验、对局状态、`GameSession` 规则内核与 Boss AI |
| `Spotlight.Runtime` | `Assets/Spotlight/Runtime/` | `Spotlight.Core`、TMP、uGUI | `Card` 与三个组件、配置 SO 与加载、UI 视图、动效、调试面板 |
| `Spotlight.Editor` | `Assets/Spotlight/Editor/` | 编辑器程序集，仅编辑器编译 | Excel 读取/校验/编译、资产发布、默认工作簿、外观模板、字体与菜单、运行与构建门禁 |
| `Spotlight.Tests.EditMode` | `Assets/Spotlight/Tests/EditMode/` | `Spotlight.Core`、`Spotlight.Runtime`、`Spotlight.Editor` | EditMode 行为与配置测试（仅 Editor 平台） |

依赖方向单向：Tests → Editor → Runtime → Core。运行层不得引用编辑器或测试程序集。

生成产物（只读，禁止手工修改）：

- `Assets/Spotlight/Generated/Cards/<id>.asset`：卡种定义 SO，三个组件配置作为子资产保存（`<id>_Combat` / `_Resource` / `_Teleport`）。
- `Assets/Spotlight/Generated/Cards/<id>.prefab`：卡种 Prefab，保存组件组合与 SO 引用，不重复存储数值。
- `Assets/Spotlight/Generated/Resources/SpotlightConfig.asset`：主配置资产，运行时通过 `Resources/SpotlightConfig` 加载。
- `Assets/Spotlight/Generated/ConfigManifest.asset`：编译清单，记录源工作簿路径、源文件摘要（SHA256）、编译时间与全部产出路径。

## 4. 玩法操作说明

- **出牌**：点击手牌 → 棋盘高亮可部署格 → 点击目标格落子。升级卡高亮的是可被覆盖的己方目标；星门在场时会额外高亮其上下左右。
- **选中单位**：点击棋盘上的单位，棋盘下方显示完整名字、生命、攻击、射程与移动距离；可移动格、可攻击目标、可互换目标分别以不同颜色高亮。
- **移动/攻击**：选中己方单位后点击高亮格移动（按最短可通行路径，允许转弯），或点击高亮敌方目标/家攻击。移动或攻击后本回合不能再行动。
- **互换**：选中己方单位后，相邻可互换的己方卡牌以紫色高亮，点击即交换位置；双方本回合都不能再行动。未开启 `rules.adjacentSwap` 时点击其他己方卡牌只切换选中对象。
- **家移动**：己方回合点击自己的家，可在己方区域内上下左右移动一格（每回合一次，不消耗资源与出牌次数）。
- **结束回合**：点击“结束回合”。若手牌超过上限，先进入弃牌阶段：点击手牌弃至上限后才能进入对手回合。
- **Boss 模式**：默认 AI 控制，Boss 回合自动结算（恢复行动 → 补兵 → 按部署顺序行动 → 自动结束），界面隐藏 Boss 操作按钮并显示兵位计时。勾选“玩家控制 Boss”后进入手动模式：可放牌、移动、攻击 Boss 单位与家；未放足时可点击“跳过放牌并结束”。
- **重开**：点击“重开”或对局结束后的“再来一局”重新开局；日志面板记录每次行动的坐标与结果。

## 5. 调试面板（仅编辑器与 Development Build）

- 入口：顶部操作条上的“配置/调试”按钮（与“重开”同一行）。正式构建（非 Development Build）不会创建该面板，按钮也会被隐藏——判断集中在 `DebugSupport.IsDebugAvailable`。
- 打开面板 `Tools/Spotlight/生成演示场景` 时已绑定；若提示“未找到 UIDocument”或“界面缺少 debug-panel”，说明场景缺失 UXML 绑定。
- 能力：
  - 编辑卡种与卡组数量、新增临时卡种（新增后需在卡组里设置数量才能应用）；
  - JSON 草稿导入/导出：导入旧格式时会在提示里列出被移除的字段（`cost`、`diagonalMove`、`counterAttack`、`chainDeployOnly`、旧家坐标 `row`/`col`），不建议再使用这些字段；
  - “恢复默认”：把草稿恢复为 Excel 编译产物；
  - “应用并重开”：先创建候选对局并检查 Boss 卡种，成功后才替换当前对局并重开；失败时保留原对局与草稿，并把原因写在面板状态区。
- 数据隔离：草稿、JSON 文本与临时卡种只存在于内存，退出 Play 或重启程序后丢弃；调试不会修改 `Spotlight.xlsx` 与生成资产，也不会保存战斗进度。面板只能通过“关闭”或成功“应用并重开”退出，点击面板外背景不会关闭。

## 6. 构建与运行门禁

- 构建前会执行配置门禁：检查编译清单是否存在、源工作簿摘要是否变化、生成资产是否缺失、Prefab 组件组合是否与配置一致。任何一项不通过都会抛出构建错误并终止构建。
- 进入 Play 前同样执行门禁；不通过时阻止进入 Play 并提示执行 `Tools/Spotlight/验证配置` 或 `Tools/Spotlight/编译全部配置`。
- Windows **非 Development** 构建不包含调试入口：面板不会创建，“配置/调试”按钮隐藏；请用该包完成一次完整对局作为发布前验收。

## 7. 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示“未找到配置资产，请先执行 Spotlight/编译全部配置…” | `Assets/Spotlight/Generated/Resources/SpotlightConfig.asset` 缺失或未编译 | 执行 `Tools/Spotlight/编译全部配置` |
| 进入 Play 被“配置门禁阻止进入 Play”拦下 | 配置从未编译、工作簿改后未重编译、生成资产缺失或被手工改动 | 按提示执行验证/编译；不要手工编辑 `Generated/` |
| 编译报“配置已过期” | 源工作簿摘要与清单不一致 | 重新执行 `Tools/Spotlight/编译全部配置` |
| 中文显示为方框或豆腐块 | 字体资产或 PanelSettings 未生成/未绑定 | 执行 `Tools/Spotlight/导入 TMP 基础资源` 与 `Tools/Spotlight/生成中文字体资产`，必要时重新执行 `Tools/Spotlight/生成演示场景` |
| 日志提示“HudView：未找到 UIDocument” | 场景缺少 UIDocument 或 UXML 未赋值 | 重新执行 `Tools/Spotlight/生成演示场景`，或手工把 `UI/Spotlight.uxml` 与 PanelSettings 绑定到 HUD 对象 |
| 日志提示“ConfigDebugPanel：界面缺少 debug-panel” | UXML 版本与代码不匹配 | 确认使用的是 `Assets/Spotlight/UI/Spotlight.uxml` 的最新版本 |
| 点击棋牌没有反应 | 处于弃牌阶段、模态面板打开、对局已结束或不是己方回合 | 看 HUD 的提示文字（会显示“请弃牌至上限…”或“Boss 回合…”） |
| 选中单位后没有高亮 | 单位本回合已行动、刚部署受召唤失调限制或维持费不足 | 查看单位详情里的行动机会说明 |
| 面板按钮点了没有变化 | 草稿校验未通过（名称重复、负数/小数移动距离、非法数量、无效卡种或升级目标） | 按状态区提示修正；“应用并重开”失败时原对局与草稿都会保留 |
| Excel 报错信息很多 | 校验会一次性汇总全部问题 | 按 `文件!表:行:列 原因` 从上到下逐条修复后重新验证 |

## 8. 测试与自检

- 规则与配置测试位于 `Assets/Spotlight/Tests/EditMode/`，可在 Test Runner（EditMode）中运行，或用命令行：
  `-batchmode -runTests -projectPath <工程路径> -testPlatform EditMode -testResults <结果 xml> -logFile <日志>`。
- 修改规则、公开接口、配置字段或工具操作后，需要同步更新本文与 [策划填写说明.md](策划填写说明.md)，并按 [最初版本实现方案.md](最初版本实现方案.md) 第 5 节补充回归用例。
