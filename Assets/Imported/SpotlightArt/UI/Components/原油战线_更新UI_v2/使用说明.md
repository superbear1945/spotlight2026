# 原油战线 · 更新 UI v2

本包包含这轮更新的四个小入口：暂停、设置、战斗记录、帮助。
每个入口分别包含 normal（正常）、hover（悬停）、pressed（按下）、disabled（不可用），共 16 张独立透明 PNG。

新样式采用细暖白边、深蓝面和微小橙色钉点。四态通过内沿发光、面板压下与整体灰暗区分。

图片均为 1254×1254 原始透明贴图；画布留白不等于游戏中的显示尺寸。按 1672×941 画面基准，建议按钮可见宽度约 44px，四枚合为右上角一排，间距 8px。
为保留四态共同原点，可为全部 16 张使用相同的 Sprite Rect：x=307, y=332, width=641, height=593（左下角原点），保持宽高比。此矩形已包含按钮边缘余量。素材为受控重绘，外轮廓存在少量生成差异，非逐像素注册；四态不应各自重新自动裁边。

回合计数器、“结束回合”和“对方回合”继续使用上一套独立素材；本轮只修正它们的布局：计数器固定在屏幕中轴，我方长条在左、对方长条在右。见布局说明.json。
