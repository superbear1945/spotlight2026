# 原油战线 · 外围 UI 素材 v1

本包提供独立透明 PNG，覆盖本对话中的战斗外围功能 UI 与装饰 UI。共 82 张 PNG：15 组交互控件 × 4 态 = 60 张，以及 22 张信息、底板与装饰素材。棋盘、卡牌、装备立绘不在本包范围内。

## 信息与装饰

- `01_turn`：独立结束回合四态、对方回合状态牌、我方／对方空数字回合计数器，以及原有 01 数字示例。
- `02_player_info`：我方／对方生命框、能量总数框、阵营标识。
- `03_entry_buttons`：暂停、设置、战斗记录、帮助、关闭、返回各四态。
- `04_action_buttons`：主要／次要文字按钮底板各四态。
- `05_settings_controls`：开关、页签、滑杆与滚动条。轨道、填充条、拖动柄为独立 PNG。
- `06_panels_notices`：通用功能面板、确认弹窗、悬浮说明、全局提示条。
- `07_results`：胜利与失败标题。
- `08_decor`：横向导轨、纵向导轨、转角装饰件。

## 文字与复用

生命值、能量总数、回合数、菜单文案和正文由引擎叠加。生命框保留生命标签，能量框保留能量总数标签，数值区为空。`round_counter_blank` 为我方空数字版本，`round_counter_opponent_blank` 为对方空数字版本，`round_counter` 仅为已有 01 数字示例。

文字按钮底板留空。推荐映射：

| 场景 | 主要按钮 | 次要按钮 | 其他组件 |
| --- | --- | --- | --- |
| 暂停菜单 | 继续游戏 | 设置、返回主菜单 | 通用功能面板、关闭 |
| 确认弹窗 | 确认 | 取消 | 确认弹窗底板 |
| 战斗结算 | 再来一局 | 返回主菜单 | 胜利／失败标题、通用功能面板 |
| 设置 | 确认 | 返回 | 页签、开关、滑杆、关闭 |
| 记录／帮助 | — | 返回 | 通用功能面板、滚动条、关闭 |

我方回合按既定方向将结束回合按钮放左、计数器放右；对方回合将计数器放左、对方回合状态牌放右。素材保持分离，位置在引擎中组装。

## 导入与核对

全部 PNG 保留各张生成原图的尺寸和透明通道。同一组件四态建议使用同一显示矩形和锚点，切换 Sprite；文字标签作为独立文本子对象。`组件状态索引.csv` 与 `component_manifest.json` 记录实际尺寸、不透明主体边界与文件哈希，可用于核对视觉占位。

本包为图像生成的美术素材稿。四态副本之间存在细小的边缘、纹理和位置差异；本包未进行逐像素配准。已逐张查看图像，并核验 PNG 格式、透明通道、数量与四态完整性。

## 生成记录

使用内置 image_gen 图像工具生成；交互副本逐个使用各自正常态作为参考。已有结束回合四态及原有计数器来自本对话前文。提示词规范和组件简报见 `生成简报.json`。原始 PNG 仅做字节复制和压缩归档。
