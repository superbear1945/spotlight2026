# 当前玩法

> Unity 实施约定：仅上下左右移动与互换。正式数值来自 Excel 编译生成的只读组件 SO 与卡种 Prefab；调试功能仅在编辑器或 Development Build 开放，本次运行结束后清空。表结构由 C# 定义，正式数据单元格禁止公式。
> 回合号从 1 开始，按先手方开启一轮，双方各行动一次后递增。初始手牌为空，在玩家回合开始抽牌；初始资源由表配置，默认 0。

## 棋盘与家

- 默认棋盘为 5 行 × 10 列。双方的家各占一格，开局位于左右边缘的中间行；偶数行取中间靠下的一行（从 0 开始的行号为 floor(rows / 2)）。
- 配置面板可切换玩家所在边缘，Boss 自动位于另一侧。默认玩家左侧、Boss 右侧；JSON 对应 home.playerSide（left / right）。棋盘最少两列。
- 己方区域固定为从己方边缘向内的前两列，涵盖所有行。家移动不会改变这个区域；棋盘不足四列时双方区域可能重叠。
- 每个己方回合，家可在己方区域内上下左右移动一格，也可以不动。不允许斜走、跳格或进入已有单位的格子；不消耗资源或出牌次数。首回合即可移动，下个己方回合恢复移动机会。
- 家可被攻击，开启遮挡时会阻挡同一行/列的攻击；家没有攻击力。摧毁敌方家即获胜。取消围死判负，没有部署空格也不会自动失败。
- 默认双方家各 10 血，玩家家每个玩家回合产出 2 资源，Boss 家不产出资源。

## 出牌与分类

- 卡牌按 category 分为资源卡（resource）、攻击卡（attack）与特殊卡（special）；现有战斗卡及 Boss 战斗卡均属攻击卡。家是特殊单位，不属于可部署卡牌。
- 无升级限制的资源卡可以放在棋盘任意空格，包括敌方区域，无需邻接家或其他卡牌。
- 攻击卡可放在己方边缘前两列的空格，或己方星门上下左右相邻的空格（不含斜角）。部署后的普通单位移动不受这两列限制。
- 星门为特殊卡，只能部署在己方边缘前两列的空格，不能借用星门效果向区域外部署。部署目标上下左右不能有其他星门（不分阵营），斜角不受限制；此限制只约束部署，不限制部署后的移动或互换。在场期间允许己方战斗卡部署在其上下左右空格，刚部署即可生效。效果随位置移动，离场即消失；维持费不足只禁止行动，不关闭部署效果。敌方不能借用星门部署；不产资源。
- 所有卡牌均不能放在棋盘外。普通卡不能覆盖已有单位；开启“需要覆盖升级”的资源卡只能覆盖指定类型的己方资源单位，不能放空格、敌方单位或家。默认 GE-12开采机只能覆盖 GE-1开采机，目标通过卡种 ID 关联，改名不会使关联失效。
- 被覆盖的卡牌立即进入所属阵营墓地，玩家卡会在抽牌堆耗尽时参与洗回。升级单位为满血新单位，使用升级卡属性，并遵守“刚上场不能行动”开关；升级照常占用一次出牌次数。
- 部署不消耗资源，也不立即扣维持费；次数耗尽、非玩家回合或弃牌阶段均不可出牌。
- 默认玩家每回合最多出 5 张牌。Boss 默认由 AI 控制；勾选“玩家控制 Boss”后使用手动模式，每回合默认放置 1 张 Boss 卡，并可操作 Boss 单位和家。手动模式未放足时可选择“跳过放牌并结束”。Boss 无资源限制。

## Boss AI 与补卡

- AI 固定管理三个兵位，在首次 Boss 回合开始时部署三卡。玩家先手时，开局只有双方的家，须等玩家结束回合并完成超限弃牌后才部署；Boss 先手时立即部署并行动。部署位置为 Boss 区域靠近玩家的一列，按首行、中间行、末行均匀分布，中间行取 floor((rows-1)/2 + 0.5)（非负数四舍五入）。默认内部坐标 board[0][8]、board[2][8]、board[4][8]，对应从下向上第 1、3、5 行和左起第 9 列；玩家在右侧时镜像。首次部署的单位当次 Boss 回合即可行动。
- 每个兵位独立计时；turn.bossRespawnDelay 默认为 5，必须为至少 1 的整数。第 N 回合阵亡，在第 N+间隔 回合的 Boss 行动开始时补回，双方行动合计一个回合。玩家攻击导致的阵亡适用，覆盖升级不触发补卡；非 AI 兵位单位不触发补卡。
- 补卡优先原兵位位置，被占时在 Boss 两列区域内优先前列、距原兵位行最近的空格，同距按内部行号升序。首次部署也使用该规则，包括小棋盘或玩家先手占位的情况；无空位则保留待部署兵位，下次 Boss 回合开始重试，不覆盖任何单位。补回满血新单位，遵守刚上场不能行动的开关。重开清空兵位与倒计时，并重新按先后手顺序部署。
- AI 在 Boss 回合开始恢复行动、补卡，然后按部署顺序逐个行动并自动结束回合。玩家须完成超限弃牌后才进入 Boss 回合；Boss 先手同样自动行动。首版同步结算，可从日志查看过程，Boss 家保持原位。
- 能攻击时优先：可摧毁的玩家家、可击杀普通单位、玩家家、战斗单位、资源单位、特殊单位；同级优先低血量，再按内部行列排序。无可攻击目标时，寻找通往合法攻击位置的最短可通行路径，优先最近目标，同距优先玩家家、战斗单位、资源单位、特殊单位，路径并列按上、右、下、左的方向顺序选择。
- AI 按配置移动距离沿路径推进到射程位置或当次移动上限，遵守占位、四向移动、曼哈顿射程、遮挡和每回合移动或攻击一次。移动距离为 0 且无可攻击目标、无攻击能力或无路径时待机，每次行动后按最新棋盘重新决策。胜负确定后停止后续行动和补卡。
- AI 模式不接受手动 Boss 放牌、移动、攻击和结束回合，界面隐藏相应按钮及部署高亮，并显示待补卡兵位的剩余回合或等待空位。快照提供 playerControlsBoss、bossRespawnDelay 和 bossReplacements（兵位、到期回合、剩余回合及等待空位状态）。

## 回合与战斗

- 默认玩家先手。玩家回合开始恢复己方单位行动，结算家及场上卡牌的资源产出，按部署顺序支付维持费，然后抽牌。默认资源跨回合累积；关闭配置开关则先清零。
- 维持费不足的单位本回合不能行动。家无维持费。Boss 回合恢复 Boss 单位行动，忽略资源和维持费。
- 默认每个普通单位每回合移动、攻击或参与互换一次，刚部署当回合不能行动（可配置）；资源卡也可按普通单位规则移动，无攻击力时不能攻击。
- 相邻己方普通卡牌可互换位置（同卡种或不同卡种均可），家和敌方单位不参与。配置“相邻己方卡牌可互换位置”对应 rules.adjacentSwap，默认 true；关闭后点击其它己方卡牌仅切换选中对象。双方须均可行动，已行动、刚上场受召唤失调限制、维持费不足、非己方回合、弃牌阶段或对局结束时均不可互换。
- 互换只限上下左右相邻；不能隔格互换。互换是独立行动，移动距离为 0 的资源卡也可参与。仅交换位置，保留双方身份、所属阵营、生命和属性，双方本回合都不能再移动、攻击或互换，不扣资源或出牌次数；下个己方回合恢复行动。玩家和手动 Boss 均可操作，Boss AI 当前仍按原有移动、攻击策略决策，不主动互换。
- 普通单位的移动距离为非负整数，无配置上限；0 表示不能移动。一次移动可上下左右走最多该距离的格数，允许转弯，按最短可通行路径计算，不能穿过或进入任何占位格。移动后本回合不能再移动或攻击。家仍最多移动一格并受己方两列限制。
- 攻击距离采用曼哈顿距离。默认无遮挡；可开启同一行/列单位遮挡。攻击只对目标造成伤害。
- 玩家单位阵亡后移出棋盘，仅将来源卡牌记录放入玩家墓地；主动弃牌也进入该墓地。Boss 卡牌进入独立回收区，不会进入玩家牌库。家血量归零结束对局；双方同时归零显示平局。
- 抽牌堆、手牌和墓地中的卡牌只保存身份、卡种和阵营。每次部署按本局配置创建全新的战斗单位，生命恢复为配置的初始值，并初始化行动状态；上次单位的伤势和临时属性不会带入下一次部署。在场存活单位跨回合保留伤势。

## 卡组与默认数值

- 默认卡组 24 张，六种玩家卡等量。每个玩家回合抽 5 张，手牌上限 5 张；结束回合时若超限，必须弃至上限才能进入 Boss 回合。
- 每个玩家回合开始按配置数量抽牌。抽牌堆耗尽时将玩家墓地全部洗牌并转入抽牌堆，继续完成本次抽牌（包括抽到一半才洗回的情况）。
- 仅循环已有卡牌，不额外生成新牌；若抽牌堆和玩家墓地同时为空，则本次抽牌可能不足。日志记录实际抽取数量和缺额；抽牌数量配置为 0 时不抽牌。场上单位及现有手牌不会被复制回牌库。
- 默认玩家卡组为六种卡各 4 张，共 24 张。配置界面可逐卡种修改数量（允许 0）、名字、属性，也可新增资源卡、战斗卡和特殊卡。不同卡种名字不得为空或重复（忽略首尾空格）。
- 默认属性（每回合产出 / 每回合消耗 / 生命 / 攻击 / 攻击距离 / 移动距离）：GE-1开采机为 1 / 0 / 1 / 0 / 0 / 0；GE-12开采机为 1 / 0 / 1 / 1 / 1 / 0；尖刀1为 0 / 2 / 2 / 1 / 1 / 1；灵兔2为 0 / 2 / 1 / 1 / 2 / 1；奥德修斯-1为 0 / 1 / 2 / 0 / 0 / 1；星门为 0 / 4 / 2 / 0 / 0 / 1。
- Boss 战斗卡默认生命 3、攻击 1、攻击距离 1、移动距离 1，不消耗资源；名字和上述属性均可配置。所有卡牌不再具有部署资源费用，仅保留每回合维持费。

## 扩展接口与配置兼容

- 配置面板仅通过“关闭”或成功“应用并重开”退出；点击面板外背景不会关闭。编辑期间不接受棋盘操作。关闭保留本次运行内的未应用草稿，重新打开可继续。调试草稿、JSON 文本和临时卡种仅保存在内存；退出 Play 或重启程序后丢弃。本功能不保存战斗进度，也不修改 Excel 和生成资产。
- “应用并重开”会先尝试创建新对局、检查 Boss 卡种，失败时显示错误并保留原对局及配置面板。
- cardTypes 注册具体卡种，category 必须是 resource、attack 或 special；stats 声明 name、hp、produce、upkeep、atk、range、moveDistance 等属性。兼容 configKey 读取旧属性，stats 优先；配置面板将它们展开为逐卡种属性。名字为空、重名、负数/小数移动距离、非法数量、无效卡种或升级目标均会阻止应用或导入；草稿可暂存未完成输入。
- 星门默认 deployHomeOnly 和 avoidAdjacentSameType 均为 true，分别限制己方前两列部署、禁止在同卡种单位四邻部署，按卡种 ID 判断，改名或关闭扩展部署效果不影响限制。
- permitsAttackDeploy 为 true 的单位允许己方战斗卡部署在其上下左右空格；星门默认开启，特殊卡配置面板可切换。旧配置保留原卡组数量，可在特殊卡分组增加星门数量，恢复默认则为 4 张。
- 仅资源卡支持 requiresUpgrade（布尔值）和 upgradeFrom（另一资源卡的卡种 ID）；配置面板提供勾选框和资源卡下拉列表，不允许选择自身。改名不影响目标关联。
- deck.cards 默认为六种卡各 4 张的清单；界面逐种编辑数量、汇总总数，新增卡默认数量 0。导入 null 或缺少 cards 的旧 deck 配置仍按旧总数与比例生成 resource / combat，打开面板后转换为数量清单。清单优先于旧总数及比例。
- turn.bossCardType 默认为 bossCombat，AI 模式可指定其他已注册攻击类卡种；手动模式可指定任意已注册卡种，Boss 出牌按该卡种分类及升级限制判断位置。
- 示例：在 cardTypes 添加 "archer": {"category":"attack","stats":{"name":"弓箭手","hp":3,"atk":2,"range":3,"moveDistance":2,"upkeep":1}}，再在 deck.cards 中引用 archer。新增卡种自动复用分类部署、界面颜色、行动和结算，无需增加具体卡名判断。扩展卡种未声明移动距离时兼容为 1。
- 旧格式导入 JSON 保留其他数值设置，移除卡种属性中的 cost、旧 home.player/boss.row/col 坐标和 chainDeployOnly 开关，开局统一按边缘居中规则定位。要采用全部新默认值，可点击“恢复默认”再“应用并重开”。
- 界面选择手牌后显示对应部署范围（升级卡高亮可覆盖的己方目标）；手牌展示移动距离和升级目标。选中普通单位可在棋盘下方查看完整名字、生命、攻击、射程和移动距离。手动模式的 Boss 未选单位且仍有放牌次数时显示其部署范围。己方回合点击家可查看并执行移动，AI 控制的 Boss 家保持原位。
- 选中普通单位后，可互换的己方目标以紫色高亮显示；点击目标立即交换位置并清除选中状态，日志记录双方名字和交换坐标。不可互换的己方卡牌仍可点击选中。配置开关支持草稿保存、应用重开及 JSON 导入导出；旧配置缺少 rules.adjacentSwap 时补为默认 true，非布尔值会阻止应用或导入。
- 卡种配置、卡牌记录和战斗单位分离：makeCard 创建只含 id/type/owner 的卡牌记录，getCardStats 读取独立的配置属性，makeUnit 创建带独立单位 id 和来源 cardId 的新单位，placeCard 返回部署后的新单位。手牌快照展示基础配置属性，棋盘快照展示当前单位实时属性；单位战斗状态不持久化至牌库或配置。
