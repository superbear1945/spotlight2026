## 依赖与来源

- ExcelDataReader 3.9.0（仅编辑器，`Assets/Plugins/ExcelDataReader/Editor/`），用于读取 `.xlsx`；已确认不进入正式运行包。
- DOTween Free 1.2.765（`Assets/Plugins/Demigiant/DOTween/`），用于选中、出牌、移动与受击反馈。
- SimHei 字体（`Assets/Spotlight/Fonts/SimHei.ttf`）用于中文显示，仅本地验证用途；如需商用请替换为已授权字体。
- TextMeshPro 基础资源（`Assets/TextMesh Pro/`）与 UI Toolkit 文本设置（`Assets/Spotlight/UI/SpotlightTextSettings.asset`、`SpotlightPanelSettings.asset`），两者都必须指向中文字体资产才能显示中文。
